# AgentBox 国际化设计

## 语言决策

- 支持 `zh-CN` 与 `en-US` 两个显示语言。
- 首次创建本地 Vault 时，系统 locale 以 `zh` 开头则使用简体中文，其他情况使用英文。
- 选定的语言保存在 `AppSettings.language` 中，之后启动不再受系统语言变化影响。
- 旧 Vault 没有 `language` 字段时，使用当前系统 locale 完成一次性迁移。

## 资源结构

- `src/shared/i18n/locales/zh-CN.ts`：简体中文资源包。
- `src/shared/i18n/locales/en-US.ts`：英文资源包。
- `src/shared/i18n/index.ts`：语言解析、当前语言状态、资源查找与参数插值。

文案采用 gettext 风格的“源文案即消息 ID”，例如：

```ts
t('已获取 {value0} 个模型。', { value0: models.length })
```

两个资源包必须包含完全相同的 key 和占位符。渲染进程、Electron 主进程、原生文件对话框、错误消息、备份文档和内置 Agent 工具共用同一组资源。

## 启动与切换

渲染入口先读取持久化设置，设定语言后再加载 React 界面，避免启动时出现错误语言的短暂闪烁。语言更改与其他设置一起保存，保存后轻量重载渲染页，使模块级的标签、提示建议和模型系统提示词也使用新语言。

## 维护与校验

`scripts/localize-renderer.mjs` 用于抽取消息、更新资源包及执行机械化迁移。提交新文案后应运行：

```sh
node scripts/localize-renderer.mjs generate
pnpm typecheck
pnpm test
```

`tests/i18n.test.ts` 会校验资源 key、占位符、英文包中的中文遗留以及系统 locale 决策。
